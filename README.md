# 用途地域あて（youto-chiiki）

地域の目的や、建てられるもの・建てられないものの説明を読んで、13の用途地域のどれかを当てる1日5問の学習ゲーム。正解したら、その地域の系統（住居系・商業系・工業系）も選ぶ。中学・高校の社会（公民）や、暮らしと住まいの学習に。

遊ぶ: <https://satou-aaaaa.github.io/youto-chiiki/>

- 中身は e-Gov 法令検索の都市計画法 第9条（<https://laws.e-gov.go.jp/law/343AC0000000100>）と、建築基準法 別表第二（<https://laws.e-gov.go.jp/law/325AC0000000201>）に書いてあることだけです。
- 説明は条文を短く言いかえたものです。政令で決める細かい数字や例外は省いています。公式の情報の代わりではありません。ある土地が何地域か、その建物を建てられるかは、市区町村の都市計画の窓口で確かめてください。
- 系統（住居系・商業系・工業系）は、名前に入っている「住居」「商業」「工業」の言葉で分けています。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。

作業の決まりは [AGENTS.md](AGENTS.md)。
